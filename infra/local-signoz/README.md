# Emergency judge telemetry

This is a temporary fallback while the new AWS account is under verification.
Foundry runs SigNoz from the root `casting.yaml` and `casting.yaml.lock`.
Caddy combines the UI, OTLP/HTTP, and MCP ports behind one local endpoint, and
a macOS LaunchAgent keeps a Cloudflare Quick Tunnel running.

The public hostname is generated by Cloudflare and changes if the tunnel
process or Mac restarts. For the judging window:

- keep the Mac powered on and connected;
- keep Docker Desktop running;
- do not restart `com.kathaquest.signoz-tunnel`;
- verify `https://<hostname>/api/v1/health` before sharing the demo.

This fallback is not the permanent production architecture. The CDK stack in
`infra/aws-cdk` replaces it with AWS after account verification.
